# claude-toolkit

Personal Claude Code plugin marketplace.

## Install (any machine)
```
/plugin marketplace add CenkZafer/claude-toolkit
/plugin install tool-radar@claude-toolkit
```

## Update
```
/plugin marketplace update claude-toolkit
```

## Plugins
- **tool-radar** — suggests vetted plugins, skills, MCPs and tools (with use/try/avoid verdicts) when starting or setting up a project.
